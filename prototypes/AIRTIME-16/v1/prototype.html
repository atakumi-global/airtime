What the prototype covers

Flows

  • Connection verifies before storing.
  • Timer starts, pauses, stops and creates an entry.
  • Back-fill blocks zero duration and lists new entries.
  • Budget creation updates the project summary.
  • Burn review reveals the projection detail.
  • Export runs a progress bar to completion.

Shared with the screens

  • The prototype uses the same tokens and components, not copies.
  • Every control is keyboard operable with a visible focus ring.
  • State is held in the page and resets on reload.
